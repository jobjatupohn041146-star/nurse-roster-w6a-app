# ระบบจัดตารางเวรพยาบาล 12 ชั่วโมง (Nurse Roster 12h) - แผนก W6A

เว็บแอปพลิเคชันที่สร้างขึ้นเพื่อ **ลดเวลาการทำงานของพยาบาลและหัวหน้าเวรในการจัดตารางเวร** ให้รวดเร็ว มีประสิทธิภาพ ถูกต้องตามกฎระเบียบ 100% และส่งออกเป็นไฟล์ Excel รูปแบบเดิมของโรงพยาบาลได้ทันที

---

## 🚀 วิธีเปิดใช้งาน (คลิกเดียวรัน)

เปิดโปรแกรม Terminal ในโฟลเดอร์นี้ แล้วรันคำสั่ง:

```bash
./run.sh
```

ระบบจะทำการตรวจสอบ Library, เปิดเซิร์ฟเวอร์ และเปิดหน้าเว็บที่ `http://localhost:8000` ให้อัตโนมัติ

---

## 🌟 ฟีเจอร์หลักเพื่อความรวดเร็วในการทำงาน (Speed & Usability)

1. ⚡ **จัดเวรอัตโนมัติด้วย Constraint Solver (OR-Tools CP-SAT)**:
   - กดปุ่มเพียงครั้งเดียว ระบบจะคำนวณและเกลี่ยเวรให้ทุกคนโดยอัตโนมัติภายในไม่กี่วินาที
   - ไม่ลบหรือทับวันลา คำขอหยุด หรือเวรที่กำหนดไว้เดิม (Locked Cells)
   - กระจายภาระงานและชั่วโมงการทำงานให้เป็นธรรมมากที่สุด

2. 🎨 **แถบเครื่องมือลงเวรด่วน (Quick Shift Palette)**:
   - เลือกรหัสเวรที่ต้องการแล้วคลิกหรือ **ลากเมาส์ระบายลงตารางได้ต่อเนื่องทันใจ**
   - รหัสเวรมาตรฐาน:
     - `C4` : เวรเช้า (07.00 - 19.00 น.) - สีเหลืองอ่อน
     - `P4` : เวรดึก (19.00 - 07.00 น.) - สีฟ้าอ่อน
     - `CK` : เวรพิเศษ 16 ชั่วโมง - สีส้มอ่อน
     - `X`  : วันหยุดประจำสัปดาห์ / วันหยุดนักขัตฤกษ์
     - `-`  : ออฟธรรมดา
     - `V`  : ลาพักร้อน
     - `HBD`: วันเกิด
     - `LK` : ลากิจ
     - `LP` : ลาไม่รับค่าตอบแทน
     - `c`  : อบรม / กิจกรรม

3. ⌨️ **แป้นพิมพ์ลัด (Keyboard Shortcuts)**:
   - เลื่อนเมาส์ไปชี้ช่องที่ต้องการแล้วกดแป้นพิมพ์ได้ทันที:
     - `C` = C4 (เช้า)
     - `P` = P4 (ดึก)
     - `K` = CK (เวรพิเศษ)
     - `X` = X (หยุด)
     - `-` = - (ออฟ)
     - `V` = V (พักร้อน)
     - `B` = HBD (วันเกิด)
     - `L` = LK (ลากิจ)
     - `U` = LP (ลาไม่รับเงิน)
     - `T` = c (อบรม)
     - `Del` หรือ `Backspace` = ล้างค่าช่อง

4. 🔒 **ระบบล็อกช่องเฉพาะจุด (Cell Locking)**:
   - ช่องที่เป็นวันลาหรือคำขอจะถูกล็อกไว้อัตโนมัติ (แสดงจุดสีเทาที่มุมเซลล์)
   - มีปุ่ม "โหมดล็อกช่อง" ให้คลิกล็อกหรือปลดล็อกช่องใดๆ ได้ตามต้องการ

5. 🕒 **ระบบเวร 4 วันท้ายของเดือนก่อน (Previous Month Tail Shifts)**:
   - แถบพิเศษสำหรับกำหนดเวรท้ายเดือนก่อนหน้า เพื่อป้องกันการขึ้นเวรติดข้ามเดือน (เช่น ไม่ให้ขึ้นเวรเกิน 4 วันติดกัน หรือไม่ให้ขึ้น P4 แล้วตามด้วย C4 ในวันที่ 1)
   - มีปุ่ม "เริ่มนับใหม่ตั้งแต่วันที่ 1" สำหรับกรณีที่ไม่ทราบเวรเดิม

6. 📊 **สรุปอัตรากำลังและโควตาแบบ Real-time**:
   - แถวด้านล่าง: แสดงจำนวนพยาบาลเวรเช้า (เป้า 3) และเวรดึก (เป้า 2) ต่อวัน หากไม่ครบจะเปลี่ยนเป็นสีแดงเตือนทันที
   - คอลัมน์ด้านขวา: คำนวณจำนวน C4 (≤11), CK (≤4), P4 (≤8), วันลา และชั่วโมงรวมให้ทันทีขณะแก้ไข

7. 📤 **นำเข้าและส่งออก Excel รูปแบบโรงพยาบาล**:
   - นำเข้าไฟล์ Excel ตารางเวรของเดือนใดก็ได้
   - ดาวน์โหลดไฟล์ `.xlsx` ที่มีสูตรคำนวณ สีเซลล์ และแผ่นงาน "ตรวจสอบ" ครบถ้วนตามมาตรฐาน

---

## 📋 กฎระเบียบ 5 ข้อที่ระบบตรวจสอบ

1. **ขึ้นเวรติดกันได้ไม่เกิน 4 วัน** แล้วต้องออฟอย่างน้อย 1 วัน
2. **ห้ามขึ้นเวรย้อน**: เวรดึก (P4) แล้ววันถัดไปเป็นเวรเช้า (C4 หรือ CK) ไม่ได้ เนื่องจากพักผ่อนไม่ถึง 12 ชั่วโมง
3. **ออฟธรรมดาติดกันได้ไม่เกิน 2 วัน**: วันที่ 3 เป็นต้นไปต้องเป็นรหัสลา (V, HBD, LK, LP)
4. **โควตาสูงสุดต่อคนต่อเดือน**: C4 ≤ 11 วัน, CK ≤ 4 วัน, P4 ≤ 8 วัน
5. **อัตรากำลังรายวัน**: เวรเช้า (C4 + CK) รวม 3 คน และเวรดึก (P4) 2 คน ทุกวัน

## 📁 โครงสร้างไฟล์ในระบบ

- `run.sh` : สคริปต์เปิดเว็บแอปพลิเคชัน
- `app.py` : เว็บเซิร์ฟเวอร์และ REST API
- `roster_engine.py` : เอนจินวิเคราะห์กฎและอัลกอริทึมจัดเวร (OR-Tools)
- `static/index.html` : หน้าต่างใช้งานสำหรับพยาบาล (Single Page Application)
- `static/app.js` : ฟังก์ชันระบบ คีย์ลัด และการคำนวณ Real-time
- `static/styles.css` : ชุดสีและดีไซน์หน้าจอ
- `ตารางเวร_ตค69_จัดสำเร็จ.xlsx` : ผลลัพธ์ตารางเวรเดือนตุลาคม 2569 ที่จัดสำเร็จและผ่านกฎเรียบร้อย
