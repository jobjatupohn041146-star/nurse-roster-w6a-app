# จัดเวรพยาบาล 12 ชั่วโมง

สกิลนี้จัดเวรลงช่องว่างของตารางเวร Excel และตรวจว่าผ่านกฎหรือไม่ โดย **ช่องที่มีข้อมูลอยู่แล้วถือว่าล็อก** (วันลา, X, เวรที่กำหนดไว้, อบรม) ไม่แก้ไขเด็ดขาด เพราะเป็นคำขอที่หัวหน้าหรือพนักงานอนุมัติไปแล้ว

## รหัสในตาราง
| รหัส | ความหมาย | นับเป็น |
|---|---|---|
| C4 | เวรเช้า 07.00–19.00 | ทำงาน |
| P4 | เวรดึก 19.00–07.00 | ทำงาน |
| CK | เวรพิเศษ (คิด 16 ชม.) | ทำงาน |
| c / C (พิมพ์เดี่ยว) | อบรม/กิจกรรมอื่น (ดู comment) | ทำงาน (ไม่นับกำลังเวร) |
| X | วันหยุดประจำสัปดาห์/นักขัตฤกษ์ | ออฟธรรมดา |
| `-` | ออฟธรรมดา (ตัวที่โปรแกรมจัดให้) | ออฟธรรมดา |
| V | พักร้อน | ออฟแบบมีสิทธิ์ลา |
| HBD | วันเกิด | ออฟแบบมีสิทธิ์ลา |
| LK | ลากิจ (รหัสสมมติ ถ้าหน่วยใช้รหัสอื่นให้แก้ใน `roster_lib.py`) | ออฟแบบมีสิทธิ์ลา |
| LP | ลาไม่รับค่าตอบแทน | ออฟแบบมีสิทธิ์ลา |
| H | ลาทุกประเภท | ออฟแบบมีสิทธิ์ลา |

## กฎทั้งหมด (สรุป รายละเอียดใน references/rules.md)
1. ขึ้นเวรติดกันได้ไม่เกิน 4 วัน แล้วต้องออฟอย่างน้อย 1 วัน
2. ออฟธรรมดาติดกันได้ไม่เกิน 2 วัน วันที่ 3 ขึ้นไปต้องเป็นรหัสลา ตามลำดับสิทธิ์ V → HBD → LK → LP
3. ห้ามขึ้นเวรย้อน: P4 แล้ววันถัดไปเป็น C4/CK ไม่ได้ (P4→P4 ได้)
4. ต่อคนต่อเดือน: C4 ≤ 11, CK ≤ 4, P4 ≤ 8
5. ต่อวัน: C4 3 คน, P4 2 คน

## ขั้นตอนทำงาน
1. **ถามข้อมูลที่ขาด** (ถามเฉพาะที่ยังไม่รู้ ไม่เกิน 1–2 ข้อ)
   - ท้ายเดือนก่อนหน้าแต่ละคนเป็นอะไร (อย่างน้อย 4 วันสุดท้าย) เพื่อไม่ให้เวรติดกันเกินข้ามเดือน ถ้าไม่มี ให้บอกว่านับเริ่มใหม่จากวันที่ 1
   - ข้อสมมติที่ยังไม่ยืนยันด้านล่าง
2. อ่านไฟล์ให้แน่ใจว่าเป็นเทมเพลตเดิม (วันที่เริ่มคอลัมน์ F แถว 2, พยาบาลเริ่มแถว 4) ถ้าโครงสร้างต่างไปให้ปรับค่าคงที่ใน `scripts/roster_lib.py`
3. รัน
   ```bash
   pip install ortools openpyxl --break-system-packages
   python3 scripts/solve_roster.py in.xlsx /mnt/user-data/outputs/ตารางเวร_จัดแล้ว.xlsx [--prev prev.json] [--time 60]
   ```
   `prev.json` = `{"ชื่อ นามสกุล": ["C4","P4","X","-"]}` (เก่า→ใหม่) ตัวเลือก `--no-ck` (ไม่ใช้ CK), `--ck-not-day` (CK ไม่นับเป็นเวรเช้า)
4. ตรวจซ้ำด้วย `python3 scripts/validate_roster.py out.xlsx` แล้วอ่านแผ่น "ตรวจสอบ" ที่โปรแกรมสร้างให้
5. ส่งไฟล์ด้วย present_files และสรุปสั้นๆ: ผ่านกฎหรือไม่, ใครใช้โควตา C4/P4 เต็ม, ข้อขัดแย้งที่พบ

## เมื่อจัดไม่ได้ หรือมีข้อขัดแย้ง
- โปรแกรมตอบ INFEASIBLE หรือมีรายงานคนขาด: บอกตัวเลขตรงๆ เช่น "วันที่ 12 เหลือคนที่ขึ้นเวรได้ 4 คน ต้องการ 5" และเสนอทางเลือก (ขยับวันลา, ใช้ CK ช่วย, ยืมพยาบาลแผนกอื่น) อย่าแก้ช่องที่ล็อกเอง
- ถ้าช่องที่ล็อกเดิมฝ่าฝืนกฎอยู่แล้ว (เช่น X ติดกัน 3 วัน) ให้รายงานเป็นคำเตือน ไม่ต้องแก้ให้เอง
- ตัวเลขโควตารวมค่อนข้างตึง (8 คน × P4 8 วัน = 64 vs ต้องการ 62 ต่อ 31 วัน) ถ้าคนลาเยอะ P4 จะไม่พอ ให้เตือนผู้ใช้ก่อน

## ข้อสมมติที่ต้องยืนยันกับผู้ใช้ (แจ้งไว้ในคำตอบทุกครั้งที่ยังไม่ได้ยืนยัน)
- CK นับเป็นกำลังเวรเช้าด้วย (C4 + CK รวม 3 คน)
- ลากิจใช้รหัส LK, LP = ลาไม่รับค่าตอบแทน
- แถว "อัตรากำลัง" ในไฟล์ (เช้า 3, บ่าย 3, ดึก 2) ไม่ตรงกับกฎ C4 3 / P4 2 จึงใช้ตามกฎที่ผู้ใช้ระบุ
- คอลัมน์ "รวม" เขียนเป็นสูตร C4×12 + CK×16 + P4×12 (สูตรเดิมในไฟล์ไม่สม่ำเสมอ) ส่วน HBD/LK/H นับรวมในช่อง OFF
- ไม่ได้บังคับระดับ (Senior RN/RN2) หรือ F/NF ต่อเวร ถ้าต้องมีให้แจ้ง
